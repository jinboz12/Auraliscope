# Auraliscope LABS 1.3dev build 70 测试说明

本次以已完成的 build 69 为基线，改进声谱图和实时频谱的显示与读数。没有改变 FFT、窗函数、采样点数或电平标定。

## 安装与分享

退出 LABS 和 DAW，运行 `Auraliscope LABS 1.3dev build 70.pkg`，选择 App、VST3、AU。
App 安装至 `/Applications/Auraliscope LABS.app`；插件安装至 `/Library/Audio/Plug-Ins/` 对应目录。
同名的用户目录旧插件可能影响 DAW 扫描结果，请核对实际加载版本。安装需要管理员授权。

App 为 Apple silicon，要求 macOS 13 或更新；插件含 arm64、x86_64。安装包未做 Developer ID 签名或公证，
macOS 可能需要通过“隐私与安全性”允许打开。本轮没有在朋友的机器、Intel 实机或真实 DAW 中完成验证。

## 本次改进

- 放大时间轴时，单元边缘过渡固定为一个屏幕像素，不随单元宽度增加而变模糊。
- 小窗口压缩显示时检查像素覆盖的全部单元，避免漏掉窄峰与短瞬态；极端压缩下 GPU 工作量有所增加。
- 取消历史列随时间变暗：同一电平在相同色阶、Tilt 设置下保持相同颜色。
- 实时与平均频谱改为不超出相邻测量值的平滑曲线，不再由曲线插值制造虚假的峰值。
- 精简窄窗口标题；频谱悬停显示被测频段的中心及上下界，声谱图悬停显示真实分析单元与混合窗信息。
- 悬停标签不再额外创建 FFT 分析器。更换采样率、音源或立体声/沉浸声聚合方式后重新开始平均。

## 建议测试

1. 与 build 69 比较时固定输入、窗口大小、色阶、Tilt 和显示时长。
2. 用稳定单音检查水平线和电平；用相邻双音检查是否能稳定区分，不把插值平滑误认为额外分辨率。
3. 用鼓点、短脉冲、扫频检查瞬态位置与连续性。放大至 4 秒、缩小至 15 秒，并拖动面板分隔线。
4. 在深色/浅色、左右镜像和不同窗口大小下检查文字、曲线、悬停框是否清楚。
5. 暂停后悬停和导出 PNG；恢复、Reset、切换采样率及 Stereo/Immersive，检查平均曲线重新开始。
6. 在实际工程中运行至少 10–20 分钟，关注 CPU、卡顿、连接与音频直通。不要以演示信号替代真实工程测试。

## 已验证与限制

47 项核心检查、内存检测、358 个本地化键、Bridge 分析/传输测试通过；VST3 validator 537/0，
插件到结果接收器 12/12、插件到 App 11/11 通过。四种采样率的 3600 列，共 2080800 个浮点读数与 build 69 逐位相同。
GPU 的 8509 项像素覆盖与边缘测试通过。三轮成对测试中，插件 CPU 相对 build 69 的变化约 +0.1% 至 +1.0%。

FFT 的低频分辨率与时间分辨率取舍仍然存在；48/96/192 kHz 的分析中心延迟约 85 ms，44.1 kHz 约 93 ms。
平均曲线来自收到的频谱快照并忽略静音，不是连续时间积分或噪声功率密度曲线。
压缩像素显示覆盖范围内的最大值，悬停则显示所选原始单元，两者不一定相同。请使用随包插件核对分析窗标签。
