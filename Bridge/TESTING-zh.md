# Auraliscope LABS 1.3dev build 69 测试说明

本次在 build 68 的基础上专门处理**声谱图的清晰度**。先用正弦波、相邻双音、单点脉冲、扫频和白噪声逐项测量从分析到屏幕
的每一环，找出真正造成模糊的原因，再逐一修正；电平校准（正弦波在每个分区内误差 ≤ 0.05 dB）、色阶、配色和界面保持不变。

## 安装

1. 退出 LABS 和 DAW，运行 `Auraliscope LABS 1.3dev build 69.pkg`。可同时安装 App、VST3、AU。
2. App 安装至 `/Applications/Auraliscope LABS.app`，插件安装至 `/Library/Audio/Plug-Ins/` 对应目录。
3. 如果主目录 `~/Library/Audio/Plug-Ins/` 还存在早期同名插件，请先将旧副本移出插件目录，避免 DAW 选到旧版。
4. 在 DAW 重新扫描后插入 Auraliscope Bridge，点击插件的 Open Auraliscope LABS。

安装包未做 Developer ID 签名或公证，macOS 可能要求在“隐私与安全性”中允许打开；安装需要管理员授权。
App 为 Apple silicon，要求 macOS 13 或更新版本；两种插件包含 arm64 和 x86_64。
协议没有变化：build 68 的插件仍可配合 build 69 的 LABS 使用，但只有安装 build 69 插件后，DAW 来源才会显示新的分析。

## 找到并修正的模糊原因

- **窗函数泄漏（主要原因）**：build 68 在中高频使用较短的 Hann 窗，Hann 的旁瓣从 −31 dB 开始，
  在 78 dB 的色阶范围内，一个响亮的音会在色阶底部向上下各扩散约 2 个半音（测得 1 kHz 以上宽 4.4 个半音）。
  现在凡是能分辨半音的行都改用 4 项 Blackman–Harris 窗（旁瓣低于 −92 dB），长度加倍，
  在 −3 dB 到 −78 dB 的每一级都比原来更窄：1 kHz 以上的响亮音在色阶底部只有约 1 个半音宽。
  750 Hz 以下（48 kHz）的低频行本来就无法分辨到 ±½ 半音，继续使用主瓣更窄的 Hann 窗，与 build 68 完全相同。
- **高采样率**：以前历史长度固定 8192 个采样，在 96/192 kHz 只有 43/21 ms，低中频严重变糊
  （192 kHz 时 440 Hz 的音在色阶底部宽约 ±12 个半音）。现在历史长度在任何采样率下都约为 170 ms，
  频率分辨率在 44.1–192 kHz 完全一致。实时频谱、峰值读数、琴键上点亮的音符和立体声分频段也同样分析约 170 ms
  （96 kHz 为 16384 点，192 kHz 为 32768 点），任何采样率下频点宽度都是 5.9 Hz（以前 192 kHz 时为 23 Hz，
  分不清低音的相邻音符）。
- **显示插值**：以前每一列在屏幕上被线性插值到下一列，单列的瞬态被画成两列宽、只有一个像素最亮的三角形，
  行之间也被插值。现在每个分析单元按它所代表的方块绘制，只在相邻边缘做很短的过渡（1 像素或 0.3 个单元），
  一个像素覆盖多个单元时显示其中最响的，细小的瞬态和泛音不会被平均掉。
- **瞬态覆盖**：以前短窗以 50 % 重叠排列，同样的脉冲因落点不同最多相差 3 dB（四个相同的脉冲有两个更暗）。
  现在每列的帧数保证任何时刻（包括两列之间）的权重相差不超过 1 dB。

## 其他变化

- **读数检查器**：读取的就是屏幕上画出的那个单元（不插值），显示该行的中心频率，时间读数包含分析延迟
  （每一列代表约 85 ms 之前的声音），第二行显示该处的分析方式（例如 “FFT 2048 · Blackman–Harris · 43 ms”）。
- **谐波光标**：鼠标悬停在声谱图上时，在指针上方标出该频率的 2–8 次谐波位置，方便检查泛音列或共振。
- 面板标题中的 FFT 范围随采样率显示（48 kHz 为 512–8192，192 kHz 为 2048–32768）。

## 代价

- 低频以上（约 750 Hz–6 kHz）的时间分辨率变为原来的约 1.4 倍（窗更长）；6 kHz 以上仍短于每列的 33 ms，看不出差别。
  快速扫频的亮度比以前略低几 dB（扫频在一个窗内移动的距离更大）。
- 白噪声等宽带声音的读数按分析带宽计算，高频区比低频区高（多分辨率显示的固有特性，与 build 68 相同；2–8 kHz 比 build 68 低约 1 dB）。
- 插件 CPU（每个核心百分比，三组交替测量的中位数，build 68 → 69）：8 个单声道 48 kHz 14.7 → 17.9 %，
  32 个立体声 48 kHz 32.9 → 34.5 %，8 个立体声 96 kHz 22.2 → 28.1 %，8 个立体声 192 kHz 29.6 → 34.4 %。
  小规模场景的测量波动较大（同一版本 12.5–16.2 %）。高采样率的增加主要来自更长的分析窗口（换来与 48 kHz 相同的频率分辨率）。

## 建议优先测试

- **与 build 68 对比**：同一首歌（有镲片、人声或持续和声），看中高频的泛音和镲片是否更清晰、低频观感是否不变。
- **96 / 192 kHz 工程**：在高采样率的 DAW 工程中插入 build 69 插件，低中频应与 48 kHz 一样清晰。
- **读数检查器**：播放已知频率的正弦波（例如 1 kHz、−18 dBFS），暂停后悬停，确认频率、电平和第二行的分析信息。
- **谐波光标**：在一个有明显泛音的乐器（例如低音或人声）上悬停，确认 2×、3×、4× 标记落在泛音上。
- **小屏幕与镜像方向**：主显示器 1280×720、设置 › 面板 › 方向选“镜像”，确认显示与读数正常。

## 验证范围

本机已运行全部核心检查（含 AddressSanitizer）、分析检查、传输检查、本地化检查、VST3 validator、
插件到探针和插件到 LABS 的端到端测试，并用离线渲染对比了 build 68 与 build 69 的声谱图；详见 VALIDATION.md。
本轮没有在 Logic、Cubase、REAPER、Live 等 DAW 中手动测试。
