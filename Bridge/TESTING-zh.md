# Auraliscope LABS 1.3dev build 71 测试说明

本次以 build 70 为基线，继续改进声谱图和实时频谱，使其更清楚、更易读、更专业。
声谱图的 FFT、窗函数、采样点数和电平标定都没有改变；实时频谱新增了更细的 128 个频段。

## 安装与分享

退出 LABS 和 DAW，运行 `Auraliscope LABS 1.3dev build 71.pkg`，选择 App、VST3、AU。
App 安装至 `/Applications/Auraliscope LABS.app`；插件安装至 `/Library/Audio/Plug-Ins/` 对应目录。
同名的用户目录旧插件可能影响 DAW 扫描结果，请核对实际加载版本。安装需要管理员授权。

App 为 Apple silicon，要求 macOS 13 或更新；插件含 arm64、x86_64。安装包未做 Developer ID 签名或公证，
macOS 可能需要通过“隐私与安全性”允许打开。本轮没有在朋友的机器、Intel 实机或真实 DAW 工程中完成验证。

## 本次改进

- **配色**（设置 ▸ 面板 ▸ 配色）：新增默认的“热度”（黑 → 靛蓝 → 深红 → 琥珀），电平越高色相与亮度同时变化，
  相近电平更容易区分；“主题”为原来的主题色阶；“灰度”为纯黑白。浅色外观下各配色从纸白走向深色。
  标题栏色标、频谱填充和导出图片都跟随所选配色。电平范围与色调曲线不变。
- **不再有“马赛克”**：一列（1/30 秒）在屏幕上常有 8–12 像素宽，build 70 把每个单元画成硬边方块，音乐看起来像色块。
  现在放大的单元从中心到中心平滑过渡；每个单元中心仍是精确电平；一个像素覆盖多个单元时仍显示其中最大值，
  不会把点击声或细谐波平均掉。
- **更细的实时频谱**：曲线、峰值保持和平均曲线改用 128 个频段（约 1/13 倍频程，为原来的 2 倍），来自同一个
  8192 点变换，相邻音符和中低频谐波更容易分开。单一分辨率使宽带声音在整个频率轴上标定一致
  （粉红噪声的平均曲线是一条 −3 dB/倍频程 的直线），可用于判断音色平衡。build 70 的插件仍可与 build 71 LABS
  一起使用，此时每个旧频段会显示在其两个半频段上。
- **响应速度**（设置 ▸ 面板 ▸ 响应速度）：快（与 build 70 相同）、中（新的默认值，更稳定）、慢（便于看音色平衡）。
  峰值保持和平均曲线不受影响。
- 静音时频谱区域保持空白，不再沿底边画一条亮线。
- 导出的声谱图至少 900 像素宽，标题不再被截断，并附带色标。

## 建议测试

1. 与 build 70 比较时，把配色设为“主题”、响应速度设为“快”，并固定输入、窗口大小、色阶、Tilt 和显示时长。
2. 用稳定单音检查水平线和电平；用相邻双音、和弦检查实时频谱能否分开各个音。
3. 用鼓点、短脉冲、扫频检查瞬态是否清楚、是否还有块状感。放大至 4 秒、缩小至 15 秒，并拖动面板分隔线。
4. 用粉红噪声或参考混音检查平均曲线是否平直、可读；分别试“快/中/慢”响应速度。
5. 在深色/浅色、左右镜像和不同窗口大小下检查文字、曲线、悬停框和三种配色是否清楚。
6. 暂停后悬停并复制/保存图片；恢复、Reset、切换采样率及 Stereo/Immersive，检查平均曲线重新开始。
7. 在实际工程中运行至少 10–20 分钟，关注 CPU、卡顿、连接与音频直通。不要以演示信号替代真实工程测试。

## 已验证与限制

48 项核心检查（含新增的 128 频段校准）、内存检测、368 个本地化键、Bridge 分析/传输测试通过；VST3 validator 537/0，
插件到结果接收器 12/12、插件到 App 11/11 通过。四种采样率共 2080800 个频谱/声谱图读数与 build 70 逐位相同。
GPU 的 9519 项像素覆盖、边缘与平滑过渡测试通过。插件 CPU 与 build 70 相比无可测变化（详见 VALIDATION.md）。

FFT 的低频分辨率与时间分辨率取舍仍然存在；48/96/192 kHz 的分析中心延迟约 85 ms，44.1 kHz 约 93 ms。
声谱图的高频区使用较短的窗，宽带噪声在高频会显得更亮（每缩短一半约 +3 dB），这是多分辨率显示的特性；
实时频谱与平均曲线不受此影响。平均曲线来自收到的频谱快照并忽略静音，不是连续时间积分。
压缩像素显示覆盖范围内的最大值，悬停则显示所选原始单元，两者不一定相同。请使用随包插件。
