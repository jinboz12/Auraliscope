# Auraliscope LABS 1.3dev build 68 测试说明

本次在 build 67 的基础上，**完全重写了声谱图**（分析、渲染、色阶、坐标与读数），不再包含任何第三方设计或代码，
关于 AudioSpectrogram 的致谢已从“关于”窗口、第三方声明和 README 中移除。外观与操作手感保持与以前一致
（同样的配色、琴键、坐标和默认 −90…−12 dB 色阶），同时在科学准确度上有明显提升。

## 安装

1. 退出 LABS 和 DAW，运行 `Auraliscope LABS 1.3dev build 68.pkg`。可同时安装 App、VST3、AU。
2. App 安装至 `/Applications/Auraliscope LABS.app`，插件安装至 `/Library/Audio/Plug-Ins/` 对应目录。
3. 如果主目录 `~/Library/Audio/Plug-Ins/` 还存在早期同名插件，请先将旧副本移出插件目录，避免 DAW 选到旧版。
4. 在 DAW 重新扫描后插入 Auraliscope Bridge，点击插件的 Open Auraliscope LABS。

安装包未做 Developer ID 签名或公证，macOS 可能要求在“隐私与安全性”中允许打开；安装需要管理员授权。
App 为 Apple silicon，要求 macOS 13 或更新版本；两种插件包含 arm64 和 x86_64。
插件与 LABS 之间的协议没有变化：build 67 的插件仍可配合 build 68 的 LABS 使用，但只有安装 build 68 插件后，
DAW 来源才会显示新的声谱图分析。

## build 68 的变化

**声谱图（全新实现）**

- **多分辨率分析**：每一行使用“刚好能分辨音高”的最短 Hann 窗（频率 ≥ 64 倍的频点宽度，主瓣约 ±½ 半音）：
  低频 8192 点，向上依次 4096、2048、1024、512 点，交界处在半个倍频程内平滑过渡。高频的时间分辨率最高提升
  16 倍：镲片、军鼓和起音是清晰的细线，而不是以前约 170 ms 的拖影。
- **时间对齐**：所有窗口以同一时刻为中心，宽频打击（如底鼓的“咔”与低频）落在同一列；短窗口在每 1/30 秒内
  以 50 % 重叠重复并做功率平均（Welch），不会漏掉落在两列之间的瞬态。
- **电平校准**：每一行代表一段频率范围，显示其中的最大电平，并用精确的 Hann 峰值估计修正“栅栏效应”：
  正弦波在所有分区内的读数误差 ≤ 0.05 dB（build 67 在两个频点之间最多偏低 1.4 dB）。
- **浮点历史**：显示端保存 dBFS 浮点值（不再量化为 8 位），切换色阶或倾斜时历史不会丢失。
- **读数检查器**：鼠标悬停在声谱图上，可读出该格的音名与音分、频率、距今时间和电平；悬停在实时频谱上，
  显示该频段电平和平均值。先按暂停，可以从容查看某一时刻。
- **导出图像**：在频谱面板上点右键，可“拷贝声谱图图像”或“存储声谱图图像…”：当前显示的时长，完整分辨率，
  带频率与时间坐标及说明（来源、色阶、倾斜、时间）。

**设置 › 面板 中的新选项**

- **色阶范围**：标准 −90…−12 dBFS；低电平 −114…−24 dBFS（混响尾音、底噪、交流哼声）；高电平 −72…0 dBFS（响亮的母带）。
- **倾斜**：平直、3 dB/倍频程、4.5 dB/倍频程（以 1 kHz 为支点），用于频谱和声谱图的显示；读数始终为真实值。
- **声谱图时长**：自动（按宽度 3–8 秒）、4 秒、8 秒、15 秒。
- **平均频谱**：实时频谱上的第二条虚线，表示自上次重置以来各频段的平均功率（不计静音），用于对照音色平衡。

**其他算法改进**

- 峰值读数（频率、音名、音分）和琴键上点亮的音符改用精确的 Hann 峰值估计：任何位置的频率误差 < 0.3 音分，
  电平误差 < 0.02 dB（以前在 55 Hz 处最多 2.9 音分、0.3 dB）。
- 实时频谱的 64 个频段同样修正栅栏效应。

## 建议优先测试

- **与 build 67 对比**：用同一首歌（最好有清晰的镲片、底鼓和持续的和声），对比两版声谱图；高频应明显更清晰，
  低频与整体观感应与以前一致。
- **读数检查器**：播放一个已知频率的正弦波（例如 1 kHz、−18 dBFS），暂停后悬停，确认频率和电平读数。
- **色阶 / 倾斜 / 时长**：在设置中逐一切换，确认标题栏的色阶图例随之变化，声谱图历史不被清空。
- **平均频谱**：播放一段音乐后按重置，平均曲线应重新开始；暂停或静音时平均不应下降。
- **小屏幕**：主显示器设为 1280×720，确认声谱图标题栏的图例不换行。
- **DAW 来源**：在 DAW 中插入 build 68 插件，确认 LABS 显示的声谱图与直接用音频设备时一致。
- **导出图像**：右键拷贝声谱图图像并粘贴到“预览”或聊天软件，确认坐标与画面一致；再试“存储”。
- **镜像方向**：设置 › 面板 › 方向 选择“镜像”，确认检查器的时间读数仍然正确。
