# Auraliscope LABS 1.3dev build 73 测试说明

本次是界面视觉的全面重新设计，测量本身不变：分析、插件结果、单位、坐标轴和峰值位置与 build 72 相同；
每个面板、分隔条、菜单和按钮都在原来的位置，字体保持不变。

## 安装与分享

退出 LABS 和 DAW，运行 `Auraliscope LABS 1.3dev build 73.pkg`，选择 App、VST3、AU。
App 安装至 `/Applications/Auraliscope LABS.app`；插件安装至 `/Library/Audio/Plug-Ins/` 对应目录。安装需要管理员授权。
App 为 Apple silicon，要求 macOS 13 或更新；插件含 arm64、x86_64。安装包未做 Developer ID 签名或公证，
macOS 可能需要在“隐私与安全性”中允许打开。本轮没有在真实 DAW 工程、Intel 实机或旧版 macOS 上验证。

## build 73 改进

- **背景有氛围，图表有稳定底色**：窗口背景以柔和光线承载配色；面板为半透明框体，顶部边缘受光、带柔和阴影；
  所有图表（声谱图、频谱、波形、声场、电平表、15 秒历史、VU 表盘）都画在不透明的底板上，渐变不会出现在电平颜色或曲线之下。
- **统一的形状体系**：面板圆角 16、底板 10、控件 8、标签 5。响度摘要成为独立面板，与历史和 VU 面板并列，不再嵌套。
- **控件**：分段控件为凹槽轨道加凸起的选中块；目标、上限、频段为安静的字段样式；面板按钮为圆角方块；悬停时均有反馈。
- **颜色各有一种含义**：主题色表示实时信号；墨色表示峰值保持、目标、指针和光标；赭色表示注意；余烬红只用于告警（OVER 带警告图标）。
- **统一的状态**：响度标题旁显示“实时”（主题色圆点）、“已暂停”（带暂停图标的描边标签，工具栏播放按钮变为主题色）或“待机”（空心圆）；
  去掉了每张卡片上的状态灯。
- **图表**：所有图表使用同一套网格层级；电平条在整宽凹槽中，峰值保持更清楚（距满刻度 3 dB 内为赭色）；悬停为实线十字和圆环，读数标签不透明。
- **三个峰值**：声谱图上的峰值读数改为列出最强的三个峰（音名与音分 · 频率 · 电平）：第一行为整个频谱的主峰，
  后两行为与之同时发声的次强音（即分析得到、琴键会点亮的音高峰：27 Hz–4.2 kHz，距最强 18 dB 以内，不含泛音）。
  空行保留位置，读数框大小不变。分析本身未改动，插件本来就发送这些数据。
- 与 build 72 相同，色标和频谱来源显示在声谱图标题行；电平、波形图例在标题行放得下时显示。

建议：与 build 72 在相同窗口尺寸下对比浅色/深色、立体声/沉浸声、暂停状态和过载状态；检查最小窗口和中文、韩文界面。

## build 72 内容


- **面板设置**：每个面板标题右侧有一个小设置按钮，弹出该面板的选项，选择后立即生效并保存。
  “设置”窗口中不再有“面板”页。把鼠标停在选项名称上可看到说明。
- **增强声谱图**（声谱图设置 ▸ 分析方式：经典 | 增强）：采用时频重分配，利用相位把每个频点的能量移到它真正所在的时间和频率。
  音高成为细线，起音落在正确的那一列，噪声呈细碎颗粒（类似 Visu 的 Enhanced 模式）。正弦波仍按 dBFS 读数；宽带声音按每行功率读数
  （粉红噪声呈水平）。分析由插件完成，**请使用 build 72 的插件**；旧插件仍发送经典数据，设置弹窗会提示。
  每列约 0.2 ms（48 kHz，约 0.7% 单核），只在 LABS 正在显示的插件上运行。
- **3D 视图**（声谱图设置 ▸ 视图：2D | 3D）：同一历史数据以地形显示——横向为时间，纵深为频率（20 Hz 在前），高度为电平。
  前沿沿用 2D 的时间轴，侧边标出 100 Hz、1 kHz、10 kHz。3D 下不显示琴键和悬停读数。
- **更干净的实时频谱**：曲线、峰值保持和平均曲线按频率平滑（平滑：关、1/12、**1/6**（新默认）、1/3 倍频程，按功率平均）；
  峰值保持改为一条淡线，平均曲线改为实线，填充改为单一淡色。悬停仍读取未平滑的频段值。

## 建议测试

1. 与 build 71 比较：分析方式设为“经典”、视图 2D、平滑“关”。
2. 增强模式：持续单音、和弦、鼓点、扫频、人声、噪声；对比经典模式的清晰度和读数。
3. 在 DAW 中切换经典/增强，确认声谱图连续滚动、不中断；用旧插件确认提示出现。
4. 3D 视图：改变面板大小、显示时长、镜像、深浅色和配色，确认画面稳定、无闪烁、帧率正常。
5. 每个面板的设置按钮：逐项修改，确认立即生效、重启后保留，中文与韩文界面文字完整。
6. 在实际工程中运行 10–20 分钟（增强 + 3D），关注 CPU、卡顿、连接与音频直通。

## 已验证与限制

49 项核心检查（含新的重分配声谱图检查）、内存检测、379 个本地化键、Bridge 分析/传输测试通过；
插件到接收器 14/14（含 VST3 48 kHz 与 AU 96 kHz 运行中切换到增强），插件到 App 通过，VST3 validator 537/0；
经典模式 2080800 个读数与 build 71 逐位相同；GPU 9519 项比较通过。

增强模式的噪声读数与经典不同（按每行功率），低频区只做频率重分配；快速扫频会呈逐列台阶。
3D 视图没有悬停读数。反馈请包含：build、Mac/系统、DAW、插件格式、采样率、显示设置、复现步骤，以及截图或短录屏。
