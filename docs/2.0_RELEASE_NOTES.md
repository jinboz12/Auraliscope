# Auraliscope 2.0 — Release Notes
**Build 121 · Changes since 1.2.2 (Build 62)**

Auraliscope 2.0 expands the sources you can measure, the analysis you can see, and the ways you can arrange your workspace. It adds DAW Bridge plugins, immersive analysis up to 9.1.6, whole-file analysis with PDF and CSV reports, and a reworked spectrum, spectrogram and panel interface.

## DAW Bridge plugins

- New VST3 and Audio Unit plugins analyze audio inside a DAW track or bus and send the results to Auraliscope.
- VST3 supports immersive buses up to 9.1.6.
- Audio passes through unchanged. Pause and Reset can control the plugin's measurement from the app.
- Improved instance identification, connection status and restoration when reopening projects. When several instances match, the app waits for an explicit choice.

## Immersive Soundstage

- Immersive soundstage visualization up to 9.1.6, with an orbitable, zoomable dome and Front, Top, Side and Iso views.
- A new Radiant display represents the spatial distribution of frequency bands as a glowing volume.
- Custom speaker azimuth, elevation and distance, with layout import, export and management.
- Audio MIDI Setup, SMPTE / ITU, Film and VST3 channel-order options improve multichannel routing.
- Stereo visualization offers full-band, three-band and five-band views with Dots, Outlines and Filled styles.

## Spectrum and spectrogram

- Rebuilt spectrogram with Enhanced reassigned analysis, 3D views, color maps and configurable display ranges.
- Average spectrum, peak holds, response and smoothing controls.
- Hover readouts for frequency, note name and level.
- Logarithmic or linear frequency axes and adjustable tilt from 0 to 6 dB per octave.
- New **Multi-FFT Spectrum (Beta)** combines three FFT windows to balance low-frequency resolution and high-frequency response, with presets and advanced controls. It currently requires locally captured stereo audio; Bridge sources are not supported.

## Whole-file analysis and reports

- Analyze Audio File… (**⌘O**) measures WAV, AIFF, CAF, MP3, AAC, ALAC, FLAC and other supported formats, from mono to 9.1.6.
- File analysis uses the same analysis core as live metering and can assess results against different delivery standards.
- Export a four-page loudness and master report as PDF, or readings as CSV. Reports are available for both files and live sessions.
- Progress, cancellation and failure feedback make the analysis state clear.
- Improved responsiveness during PDF export, saving feedback and a Show in Finder action.

## Loudness, levels and waveform

- Fourteen loudness and delivery presets, with editable loudness targets and true-peak ceilings.
- LU / LUFS, EBU +9 / +18 scales, overs counting and more flexible history display.
- Exact sample-peak waveforms, linear or dB display, and 2-, 4- or 8-second ranges.
- VU calibration and additional peak-hold and release settings.
- Report sections without valid measurements show as unavailable instead of passing.

## Interface and workspace

- Updated panels, toolbar, icons, light and dark appearances, and multiple color themes.
- Enlarge, hide, resize or detach panels into their own windows.
- New **Dock mode (⌥⌘S)** with selectable panels and adjustable widths.
- Saved and built-in layouts, with a layout reset action.
- Improved recovery of windows left off screen after removing a display.
- Smoother panel transitions, resizing and high-refresh-rate rendering; hidden panels avoid unnecessary drawing.
- Better space allocation when Multi-FFT is visible, keeping the other analyzer panels usable in smaller windows.

## Settings presets and six languages

- Save, load, update, duplicate, rename and delete settings presets.
- Presets are individual files for backup and transfer. Changes made in Finder are reflected in the app.
- Overwrite confirmation and clearer feedback for save failures and damaged preset files.
- English, Simplified Chinese, Traditional Chinese, Japanese, Korean and Spanish.
- A first-use guide covers source selection, panels and permissions. Updating the app no longer automatically repeats the welcome sheet.

## Capture reliability and status feedback

- Persistent device-capture failures trigger a bounded recovery sequence with visible status and a manual retry action if recovery is exhausted.
- More accurate accounting for lost audio and measurement interruptions.
- Clearer states and actions for missing sources, permissions, paused capture, disconnected devices and Bridge connections.
- Fixed false true-peak overshoot and spectrogram artifacts after Pause → Resume, while preserving cumulative measurements.
- Expanded automated coverage for analysis, lifecycle, plugin transport and reference results.

## Update checks

- Each normal launch checks for updates asynchronously, without blocking the window or audio startup.
- An available update offers release-page and installer-download actions. Downloads and installation remain the user's choice.
- Manual checks and the Include pre-releases preference remain available. Automatic failures and offline operation stay quiet.

## iPad display connection support

- Bridge can explicitly scan for, pair with and select an Auraliscope iPad display on the local network.
- An encrypted connection sends analysis results directly from the plugin. Audio is not transmitted, and the Mac app is not required as a relay.
- Each plugin instance uses one display destination. **Use this Mac** restores local display.
- Requires the companion iPad app, distributed separately. Physical iPad and Wi-Fi acceptance testing remains outstanding.

## Installation, compatibility and verification

- The Mac app requires **Apple silicon and macOS 13 or later**. System-output capture requires **macOS 14.2 or later**.
- Bridge VST3 and AU binaries are universal for Apple silicon and Intel.
- The app, plugins and installer are **Developer ID signed**. Apple notarization is deferred for this delivery; macOS may require manual approval in Privacy & Security. Verify the supplied SHA-256 checksums before installing.
- Automated checks and local-loopback tests passed. Real audio hardware, real DAWs and physical iPad / Wi-Fi acceptance testing remain outstanding. See the [integration record](RELEASE_2.0_INTEGRATION.md) and [build validation record](BUILD121_VALIDATION.md) for details.
