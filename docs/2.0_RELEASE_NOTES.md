# Auraliscope 2.0 · build 121

Build 121 brings the completed Phase 1–7 work and the build 120 interface into the 2.0 stable version line.

- Loudness, true peak, spectrum, spectrogram, waveform and immersive analysis up to 9.1.6; file analysis with PDF and CSV reports.
- Bounded capture recovery, lost-frame accounting and safer DAW source selection.
- Bridge VST3 and AU: explicitly scan, pair and select an iPad display over encrypted local-network transport. Analysis results only; no audio transmission. Use this Mac restores local transport. One destination per instance. The iPad application is distributed separately.
- Pause → Resume no longer joins discontinuous audio in true-peak and spectrogram analysis; accumulated measurements continue.
- An asynchronous update check on each normal launch, with explicit download actions and quiet offline handling.
- Clearer status actions, cancelled and failed file-analysis states, report saving feedback, preset error feedback and overwrite confirmation.
- Off-screen window recovery and usable analyzer panel sizing with Multi-FFT visible. Multi-FFT remains Beta and requires local stereo audio.

## Requirements and verification

The Mac app requires Apple silicon and macOS 13 or later; output capture requires macOS 14.2 or later. Bridge VST3/AU binaries are universal.

Automated analysis, golden reference, lifecycle, update, localization and plugin transport checks passed during integration. VST3 network and AU streaming were checked with local loopback and a test host. Real audio hardware, real DAWs, physical iPad/Wi-Fi, and prolonged hardware operation have not been validated on this release source. See [integration record](RELEASE_2.0_INTEGRATION.md) for evidence, security limitations and acceptance steps. Developer ID signing and Apple notarization status are recorded separately with the delivery.

## Signing

Developer ID signed app, VST3, AU and installer. Apple notarization is deferred for this delivery. macOS may require manual approval in Privacy & Security. Verify the supplied SHA-256 checksums before installing.
