# Loudness measurement references

Build 108 presents commercial delivery references with neutral use descriptions. The preset's target, true-peak
ceiling and rule remain visible. Existing saved preset identities and all measurement values are unchanged.

Technical standard names remain where they identify the measurement method or reference: ITU-R BS.1770,
EBU R128, EBU Tech 3341/3342, ATSC A/85, ARIB TR-B32, OP-59 and ASWG-R001.

- Integrated loudness uses programme loudness with the BS.1770 gates. It is not a dialogue detector.
- Delivery rules compare the displayed integrated loudness with the target and tolerance, plus the true-peak ceiling.
- Maximum rules check an upper loudness limit and true peak.
- Normalization references describe a gain difference relative to a chosen playback level; they are not delivery certification.
- Mastering references show the difference from an aim. Tonal balance, bandwidth and dynamics checks are guidance.

The film/series dialogue reference retains its dialogue warning because full-programme loudness can differ from
dialogue-specific measurements. Selecting it does not enable dialogue-gated analysis.

Presets are convenient measurement references, not a guarantee of acceptance by any distributor. For a delivery,
use the numeric requirements in the actual specification or agreement and set a custom target and ceiling if needed.
