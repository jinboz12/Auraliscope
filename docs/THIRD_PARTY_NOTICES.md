# Third-party notices

## AudioSpectrogram

The spectrogram presentation in Auraliscope was adapted from the ideas in
[AudioSpectrogram](https://github.com/lmshao/AudioSpectrogram): a dB legend
and explicit time and frequency markers. Auraliscope's current palette
and real-time interface are its own. The
real-time implementation is original Swift, Accelerate and Metal code; no Rust
library is linked into the app.
