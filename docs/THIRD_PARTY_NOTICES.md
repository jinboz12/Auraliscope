# Third-party notices

Auraliscope contains no third-party source code and links no third-party library: its Swift, C and Metal code is
written for the project, and it uses only Apple's system frameworks. The spectrogram, including its analysis,
rendering, colour scale, axes and inspector, is the project's own design and implementation (since 1.3dev build 68).
