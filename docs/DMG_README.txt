Auraliscope — test build
========================

1. Drag the Auraliscope app onto the Applications folder.
2. Open it from Applications. macOS will say it cannot verify the developer:
   this build is signed for testing only and is not notarized by Apple.
3. Open System Settings > Privacy & Security, scroll down, and click
   "Open Anyway" next to Auraliscope. Confirm, and it opens from then on.

To meter what the Mac plays, allow System Audio Recording when asked
(macOS 14.2 or later). To meter an input, allow the Microphone.
Audio is analysed in memory only; nothing is recorded or sent anywhere.

Found a problem? Help > Show Diagnostic Logs opens the logs folder
(events only, never audio). Send the newest file with a short note.

Requires a Mac with Apple Silicon and macOS 13 or later.


Auraliscope — 测试版
====================

1. 将 Auraliscope 拖到“应用程序”文件夹。
2. 从“应用程序”中打开。macOS 会提示无法验证开发者：
   此版本仅为测试签名，未经 Apple 公证。
3. 打开“系统设置 > 隐私与安全性”，向下滚动，点按 Auraliscope 旁的
   “仍要打开”并确认，之后即可正常打开。

如需监听 Mac 播放的声音，请在提示时允许“系统音频录制”
（需要 macOS 14.2 或更高版本）；监听输入则需允许“麦克风”。
音频只在内存中分析，不会被录制或发送到任何地方。

遇到问题？“帮助 > 显示诊断日志”会打开日志文件夹
（只记录事件，不含音频）。请把最新的文件连同简短说明发给开发者。

需要搭载 Apple 芯片、运行 macOS 13 或更高版本的 Mac。
