# Auraliscope 2.0 RC 1 — Build 117

Build 117 continues Build 116. App 2.0 / 117; Bridge VST3 and AU 2.0.117.
No installer execution, GitHub publication, sale, tag or remote push is part of this preparation.

## Build 117 Multi-FFT optimization

- The Multi-FFT engine converts only the bins each zone contributes to the fused display, with vectorised windowing
  and reused scratch: about 7× less processing for the same calibrated curves, verified against the previous
  exhaustive computation and the existing numerical checks.
- The panel redraws its grid and labels only on axis changes or resizes, and keeps the running engine when the
  panel moves between the grid, the Dock and an independent window.

## Build 116 Multi-FFT sizing and Dock

- A draggable divider between Multi-FFT and the original analysis stack saves height share and resets on double-click.
- With Stereo local PCM and Beta enabled, Multi-FFT replaces the original Dock spectrum slot, inheriting position
  and width. Disabling Beta restores the original panel at the current width. Mono/Immersive/Bridge retain the
  original spectrum. Existing layouts with both spectrum IDs are normalized to one shared slot.
- Dock resizing, reorder/removal, independent windows and hidden-panel rendering use the resolved panel identity.
  Compact headers/readouts adapt to narrow cards; an overconstrained Dock keeps all selected panels nonzero.

## Build 114 spectrum architecture Beta

- Optional Stereo-only **Multi-FFT Spectrum (Beta)** panel, hidden on first launch and on upgrade. Enable it in
  Spectrogram & Spectrum ▸ Panel settings, or the window Panels menu. It has independent Low/Mid/High FFTs,
  five performance presets, Precision/Balanced/Responsive policies and editable advanced settings.
- Common sample-centred windows and logarithmic raised-cosine power crossfades. Separate tone-amplitude and PSD
  calibrations, Hann/Blackman–Harris windows, time/frequency smoothing, L/R and optional M/S.
- Local Classic Spectrum and Spectrogram default to a single shared 4096-point Hann STFT; 2048/8192 and the exact
  original Build 113 analysis remain selectable for A/B. Switching refills only FFT history, retaining loudness
  and held peaks. Enhanced and Immersive use the original analysis.
- The new engine exists only while its panel is displayed in Stereo. DSP runs on the consumer queue with a
  sample-based cadence, independently of the panel's 30 Hz drawing. The audio callback is unchanged.
- **Beta limit:** local devices and system audio only. Bridge still sends its original results; new Multi-FFT
  results/configuration transport is not implemented. It is shown explicitly as unavailable on Bridge sources.
- The installer retains the production bundle identities and fixed install paths, replacing the installed app
  and selected Bridge formats in place.

## Build 113 status bar

  Measured on build 112: 30 fps gave 29.9 refreshes/s (17.0 % CPU), 60 fps 59.9 (25.5 %) on a 60 Hz display.

## Earlier RC changes

- Reuse a canvas renderer and its vertex storage across grid/enlarged/Dock handover; avoid allocating them again
  for every panel move. Build an enlarging panel with its moving labels already held, avoiding an unnecessary
  text-tree creation and teardown. Preserve the existing layout, content, themes and source images.
- Share the GPU resource permit across renderers that use the same scene, protecting mutable scene textures during
  grid/enlarged/Dock handover and appearance changes. Retry redraw requests after a busy GPU or missing drawable.
- Stop settled scenes after two elapsed seconds at any refresh rate; previously 120 frames meant one to four seconds.
- Hold hidden VU needles with the other canvases during transitions. Continue digital readout publishing for a
  visible detached panel while the main window is hidden.
- Cache unchanged speaker geometry; saving, selecting, importing, deleting and reloading a layout invalidate it.
- In Dock mode, measure the full window above the native title-bar safe area at the outer layout root. This removes Build 107's empty top bar while keeping panel titles and bottoms within the measured bounds; normal toolbar spacing returns outside Dock mode.
- Add GPLv3 licensing and notices to the app, plugins, installer and source distribution; document paid official
  builds and recipients' GPL redistribution rights consistently in English, Chinese and Korean README sections.
